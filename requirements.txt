# Financeiro Pessoal

Aplicativo local para controle financeiro pessoal em Python, com interface em CustomTkinter e persistência em SQLite.

## Estrutura do projeto

- `financeiro_pessoal/` — pacote principal
- `main.py` — ponto de entrada do programa
- `requirements.txt` — dependências do projeto
- `tests/` — testes automatizados

## Requisitos

- Python 3.10+
- pip

## Instalação

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Execução

```bash
python main.py
```

## Funcionalidades da base implementada

- Banco SQLite local, persistente e organizado
- Estrutura modular para receitas, despesas, serviços e interface
- Cálculos financeiros centrais validados por testes
- Configuração do caminho do banco em diretório do usuário
